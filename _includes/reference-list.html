{%- comment -%} Renders a list of references from _data/references.yml. Usage: {% include reference-list.html refs=site.data.references.publications %} Each entry supports: authors, year (optional), title, venue, links (optional list of url/label pairs). Values may contain inline HTML; they are emitted unescaped, so write literal ampersands as &. The template handles two things so the data file doesn't have to: - Sebastian Benthall's name is bolded wherever it appears in `authors`. - `venue` is italicised. Don't put or in the data for those; any existing is stripped first so old entries don't end up double-wrapped. {%- endcomment -%}
